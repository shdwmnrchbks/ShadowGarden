# v2.5 Motion Slice 3 — Series + Reader

- Series observes canonical renderer output rather than calculating reading state itself.
- When a volume rerenders, its existing `data-reading-state` and rendered progress width are compared with the previous rendered card; state surfaces cross-fade/pulse and progress visually interpolates to the new renderer-owned value.
- Initial Series hydration gives information/body content a restrained reveal while preserving the Library→Series cover transition target from Slice 2.
- Reader uses the shared motion language without changing Reader session, flow, progress, or auto-hide ownership.
- The existing `reader-chrome-hidden` controller now receives asymmetric motion: faster dismissal and gentler reappearance.
- Reader drawers use shared enter/exit easing, progress text gets a small value-change pulse, and the EPUB viewer receives a one-time ready reveal after canonical loading completes.
- Reader opts into same-origin cross-document View Transitions so Series↔Reader continuity can use the shared root transition where supported.
- Unsupported browsers and reduced-motion users retain the same functional state/navigation paths without optional animation.
