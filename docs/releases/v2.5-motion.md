# Shadow Garden v2.5 — Motion & Continuity

The motion milestone is delivered in four verified slices so regressions remain isolated and reversible.

1. Motion foundation — shared timings/easings, progressive View Transition helper, reduced-motion contract.
2. Library motion — filtering/sorting continuity, Grid/Compact morph, skeleton/content handoff, Library→Series continuity.
3. Series + Reader motion — reading-state/progress interpolation, Reader chrome refinement, Series↔Reader continuity.
4. Keeper + navigation continuity — dialogs, save/upload lifecycle, navigation choreography, final release reconciliation.

Slice 4 completes the implementation surface. Motion remains progressive enhancement and does not become a state owner. It also does not become a persistence, workflow, API-request, or navigation owner.
