# v2.5 Motion Slice 2 — Library

- Main and Adult shelves share the same motion layer.
- Filter, sort, reading-state, pinned, and Grid/Compact changes replay the existing controller event inside progressive View Transitions; URL/preferences/catalog state remain owned by the existing Library controller.
- Catalog cards receive stable transition identities so surviving cards move and resize into their new positions instead of forcing a whole-grid replacement fade.
- First catalog hydration reveals real cards from skeleton geometry without an intermediate blank state.
- Mobile filter groups and active pills use restrained unfold/insert choreography.
- Recently Added keeps native momentum/snap behavior and gains a quiet trailing continuation fade on mobile.
- Library → Series navigation promotes only the chosen cover into a shared `series-cover` snapshot. The destination is the static Series first-paint cover skeleton, so the transition is independent of asynchronous catalog timing.
- Reduced-motion users keep all state changes with optional animation suppressed.
