# Shadow Garden v2.0.0

Shadow Garden v2.0.0 is the completion of the R0–R10 full-codebase refactor. It preserves the existing private-library product and security behavior while replacing the accumulated v1 patch architecture with explicit domain, UI, Reader, Garden Keeper, service, design-system, test and build/deployment ownership.

## Highlights

- Canonical browser-local reading state: **Unread → Read**, **In Progress → Continue**, **Finished → Read Again**.
- One Library/Series rendering and volume-action pipeline across Main, Adult, Series, Recently Added and reading banners.
- Reader application architecture with explicit authorized book sessions, Page Map, Pages/Continuous adapters, native Continuous touch scrolling and isolated focused-image pinch/pan.
- Garden Keeper composition root with one AdminClient and isolated Authentication, Library/Series, Upload, Maintenance, History, Trash, Abuse Watch and version workflows.
- Thin Cloudflare Pages Function routes over explicit auth/media/catalog/storage/validation/abuse/http/admin services.
- Semantic CSS/design-system ownership with the final historical Keeper CSS aliases removed.
- Reconciled mobile navigation behavior: viewport-fixed drawer, pinned open header, stable background layout, document-level touch/scroll lock and independently scrollable drawer.
- Layered deterministic unit, service, DOM and browser-contract tests with reusable high-risk fixtures.
- Locked Node 22/npm build pipeline using `npm ci`, deterministic deployment metadata and generated `dist/`.
- Final v2 source tree has no grandfathered patch-style runtime files and no authored local JS/CSS release query strings.

## Security

Security Milestones 1–9 remain intact: private B2 storage, signed media tickets, opaque `bk_...` identities, Garden Pass/Turnstile, signed Keeper sessions, server-authoritative cooldowns, HMAC-derived abuse state without raw-IP persistence, opaque `cv_...` covers, protected Range delivery and public catalog redaction.

R8 also permanently restricts signed EPUB ticket normalization to `/media/shadow-garden/books/`.

## Upgrade and data compatibility

No account migration is required. Reading progress, bookmarks, Finished state, pinned state and Reader/Library preferences remain browser-local. Existing live persistence aliases are intentionally retained so the v2 cutover does not discard established browser reading data.

The public site continues to use Cloudflare Pages with the private Backblaze B2 bucket and the same accepted HTTP/security routes.

## Verification

The release is created only after:

1. the R10 merge commit passes the complete GitHub Verify suite and production build;
2. the matching v2.0.0 commit is visible in production `version.json` on `shadowgarden-bon.pages.dev`;
3. Main Library, Adult Library, Series and Reader public deployment smoke requests succeed.
