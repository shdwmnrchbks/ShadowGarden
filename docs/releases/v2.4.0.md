# Shadow Garden v2.4.0 — Interaction & UX Polish

v2.4.0 was intentionally delivered as several focused PR slices. The initial release PR (#133) promoted the first five slices (#128–#132), but that release summary did not represent the entire UX plan. The later completion slices below reconcile the remaining plan items without changing the package version.

## Delivered slices

### #128 — Library Search & Discovery

- Context-aware filter counts and disabled zero-result choices.
- Active-filter removal and `Clear all` behavior.
- Actionable empty states.
- Per-shelf Grid/Compact and sort persistence.
- Reduced-motion-aware result transitions.
- Read-suggestion reroll agency.

### #129 — Reading Progress & Series

- Library/Series progress rails.
- Canonical Unread / Continue / Up next / Finished states.
- Existing reading-state owner reused for preferred entries.
- Long-Series Back to top affordance.

### #130 — Reader Interactions

- Staged Reader loading state.
- External-link affordance with confirmation.
- Press/tap feedback.
- Immersive mobile chrome with Continuous-mode rail preservation.

### #131 — Garden Keeper

- Dirty-aware Series editing and discard protection.
- Persistent save footer.
- Recoverable Trash hierarchy.
- Canonical Genre editing.
- Upload review summary and dialog focus restoration.

### #132 — Loading / Perceived Performance

- Main/Adult Library first-paint skeletons.
- Grid/Compact first-paint preference preservation.
- Series hero/volume skeletons.
- Adult Series theme established before visible loading content.

## Plan-completion slices after the initial release

### #134 — Library navigation, filters, and sorting

- Navigation drawer opens without changing document geometry.
- Sticky header stays in flow; fixed-header/body-padding compensation is retired.
- Mobile Search remains a stationary anchor while filter controls unfold underneath it.
- Filter expansion uses reduced-motion-safe transitions after the flash-free initial collapsed paint.
- Stronger keyboard-visible navigation and Library focus states.
- Sort choices expanded while preserving old keys and URL/local preference compatibility:
  - Recently added / Oldest added
  - Title A–Z / Z–A
  - Author A–Z / Z–A
  - Year newest / oldest
  - Most / Fewest volumes

### #135 — Series hierarchy and volume interaction polish

- Stronger hero title/byline spacing and hierarchy.
- Preferred reading action gains extra visual emphasis when its canonical state is Continue.
- Description/section rhythm improved.
- Volume cards become coherent hover/focus surfaces.
- Volume title/state/meta/action alignment improved without changing the shared Reader action pipeline.
- Main/Adult and reduced-motion variants preserved.

### #136 — Reader toolbar and progress polish

- Stronger book-title vs chapter-title hierarchy.
- More legible Reader control spacing and Return affordance.
- Clearer keyboard-visible focus treatment.
- Pages progress percentage becomes a stable tabular readout.
- Continuous progress text gains matching hierarchy.
- Reader EPUB typography remains owned by Reader settings, not outer chrome CSS.

### Final shared completion slice

- Recently Added cards separate volume title, series title, and added date instead of truncating series/date into one line.
- Recently Added, Grid, and Compact cards receive consistent whole-card focus/hover affordances.
- Mobile Recently Added card rhythm is widened slightly for more readable metadata.
- Navigation architecture documentation is reconciled with the no-layout-shift implementation.
- Regression tests cover the plan-completion contracts.

## Duration-sort constraint

The original UX exploration included a possible Duration sort. Shadow Garden currently has no canonical duration, reading-time, or word-count metadata in the catalog or ingestion pipeline. v2.4.0 therefore does **not** substitute file size or another misleading proxy for duration.

A real Duration sort requires a separate metadata/schema + ingestion owner before it can be exposed honestly in the Library UI. All other v2.4 UX-plan items are reconciled in this release line.

## Release invariants

- Package version remains **2.4.0**; these are completion slices of the same UX milestone rather than a new feature release.
- No new backend API owner was introduced by the completion slices.
- Existing reading-state, Reader progress, EPUB layout, and Garden Keeper persistence owners remain canonical.
- Main/Adult parity, keyboard focus, `prefers-reduced-motion`, increased-contrast, and forced-colors contracts remain part of the design system.
