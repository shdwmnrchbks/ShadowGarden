# Shadow Garden v2.6.4 — Continuous Canvas Rail Exclusion

Shadow Garden v2.6.4 resolves the reopened issue #160 item 2 by changing how Continuous mode reserves the seek rail, per the owner's direction: the reading canvas itself now ends exactly where the seek rail begins.

## Changed

- The EPUB viewport (`.viewer`) is excluded from the seek-rail column in Continuous mode — `right: 34px` on wider layouts and `right: 22px` on mobile widths — instead of spanning underneath a floating rail while publication padding simulated the reservation. Nothing rendered inside a chapter frame can reach Reader chrome because the canvas no longer extends there.
- Publication bodies keep symmetric `2.5em 4vw` reading margins; the previous asymmetric `max(4vw, 22px/34px)` right-gutter padding is gone because structural exclusion replaced it.
- All v2.6.1–v2.6.3 containment rules stay as defense-in-depth: wrapper max/min-width caps, static untransformed replaced media, and `overflow-x: clip` on the publication viewport now clip at a boundary that coincides with the rail's left edge.

## Regression coverage

The generated Reader EPUB fixture ships five oversized shapes in the Wide Visual chapter: figure-wrapped, bare-div-wrapped, `min-width: 900px` canvas, full-width dark plate, and an absolutely positioned canvas anchoring against its closest positioned ancestor. The mobile real-browser regression requires every shape's rendered right edge to sit at or left of the fixed Continuous seek rail in parent-page coordinates. The reconciliation guard pins both canvas-exclusion rules so the contract cannot silently regress.

The complete v2.6 Chromium, Firefox, WebKit, Chromium Mobile, and WebKit Mobile regression matrix remains required, together with the reusable v2 publisher production gates.
