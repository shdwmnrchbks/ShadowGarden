This directory primarily contains immutable formal release records. Release-note files such as `v2.10.0.md` describe shipped versions and are not active planning documents.

The older `v2.5-motion*.md` files are completed Motion & Continuity planning/milestone records retained here for historical-link compatibility. Their canonical planning archive is under [`../archive/v2.5-motion/`](../archive/v2.5-motion/).

Do not create new roadmap slices in `docs/releases/`. Active planning belongs in [`../roadmaps/CURRENT_ROADMAP.md`](../roadmaps/CURRENT_ROADMAP.md); audit evidence belongs under [`../audits/`](../audits/); completed planning belongs under [`../archive/`](../archive/).
